## 整合中修复

1. 上传记录补齐按 20 条分页，否则移除旧“加载更多”后只能访问前 20 条；作品列表继续按 50 条分页。
2. 快速切换列表 / 搜索时，后发请求可替代前一个请求；迟到响应不再覆盖新视图。进入账号或设置页会取消旧列表结果。
3. 从编辑器回到已有社区浏览时保留搜索、排序、详情与滚动位置；只有实际退出用户中心才重置对应布局。首次打开用户中心的消息排队与后续“浏览社区”选择保持一致。
4. 新画廊与公开主页使用与原卡片相同的应用前缀、一次原图降级和损坏占位；更换头像时清理旧降级状态，避免第二张头像失去降级机会。
5. 头像上传 / 移除不再覆盖已填昵称等草稿；后台资料读取也不会覆盖已编辑字段。迟到的资料请求不能重新登录已经退出的账号。失效登录会退出用户中心并同步主站。
6. 资料接口拒绝非对象 JSON 和非法字段；头像除路径 / 5MB 检查外还验证真实图片及像素边界。公开主页说明与实际展示字段一致，密码哈希和本人收藏明细不在公开资料中返回。
7. 保留服务器 `LANDSCAPE_DB` / `LANDSCAPE_UPLOAD_DIR`，本地默认数据库统一到 backend；隔离测试显式指定临时数据目录。
