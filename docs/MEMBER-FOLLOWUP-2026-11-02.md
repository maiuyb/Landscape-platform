# 成员改动后续修正与回归 · 2026-11-02

基于 main/3a46984，对照 [用户中心说明](ISSUE-USER-CENTER-2026-10-31.md) 与 [UI 修改记录](UI修改记录-2026-10-31.md) 修正复现的问题并补齐自动化检查，保留成员的界面布局与 Gallery 美术。

## 修正

- 显示偏好更新只同步动效，不再重新赋值当前照片的导出选项。新照片读取最新默认格式、尺寸和质量，已有照片各自保留手动选择，切换照片后恢复相应选项。
- 动效、作品列数的样式与点击绑定限定到设置面板的按钮，排除带相同 data 属性的 html 根元素，避免普通页面点击保存偏好或给根元素添加 active 类。
- 隐私按钮按当前会话顺序保存，迟到的资料读取不能覆盖后续修改；更新响应只合并此次改变的字段。后端资料／隐私使用白名单字段的单条部分更新，不把请求开始时读到的其他字段写回，避免并发覆盖。
- 就地登录页面保留 toast，并置于登录框遮罩上方，让注册与找回密码的发码反馈可见。找回密码返回登录或重新打开认证窗口时，清理隐藏的邮箱、验证码和新密码字段；登录框按既有设计可预填刚设置的新密码。

显示和导出偏好仍属于当前浏览器；公开主页隐私仍按账号在后端保存。本轮没有引入跨设备偏好同步或改变已有产品规则。

## 新增自动化检查

`tests/test_member_account_features.py`：8 项后端检查，使用临时数据库与内存邮件，覆盖：

- 重置后旧密码不可用、本人所有旧会话失效、其他账号会话与原有资料／积分保留。
- 重置验证码用途隔离、过期、错误次数、单次使用、并发唯一成功及请求频率限制。
- 未绑定邮箱不能通过重置创建账号。
- 隐私字段本人可见、公开接口隐藏、账号边界和严格布尔校验。
- 同时修改两个隐私字段及简介不会互相覆盖；该检查在修复前可复现失败。
- 本人作品／收藏搜索、分类、数量与分页范围，拒绝未登录和无效分类范围。

`tests/member-followup-browser.cjs`：根路径与 `/landscape` 下完成真实界面流程，覆盖：

- 默认及显式列数启动时，页面空白点击不写入偏好。
- 改字号、动效、列数、排序与导出默认值后，当前照片导出选择保持，新照片读取新默认值，原照片切回后仍保持选择。
- 社区、本人与收藏组合搜索、分类、空结果、个人主页地址及返回社区搜索词恢复。
- 快速隐私操作按序保存；故意延迟的旧资料响应不能回滚隐私状态，公开与本人资料响应保持正确。
- 就地登录取消／成功、密码显示切换、退出及找回密码全过程保留照片像素、配方与撤销／重做历史。
- 找回密码发送提示可见、返回登录预填新凭据、清理隐藏敏感字段、撤销旧会话及重新登录。
- 设置页手机宽度无横向溢出，并检查设置和恢复后登录截图。

隔离测试账号可选绑定 `@example.test` 合成邮箱，不复用真实 SMTP，不影响生产注册流程。生产代码无测试账号入口。
