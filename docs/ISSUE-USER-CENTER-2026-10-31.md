# Issue 说明：用户中心、个性化设置与作品筛选（2026-10-31）

当前基线：`main` / `4994bb5`。

## 背景

用户中心、个人主页、作品管理和社区搜索之间存在入口不统一、搜索范围不明确、设置项分散的问题。本轮集中整理用户中心的信息层级，并把搜索、筛选、显示偏好和隐私控制放到对应页面内，减少跨页面跳转和误搜。

## 交付范围

### 用户中心

- 侧栏顺序调整为：个人主页 → 账号管理 → 我的作品 → 我的收藏 → 常用配方 → 个性化设置。
- 账号管理卡片顺序调整为：编辑资料 → 修改密码 → 显影积分与开发者赞助 → 登录账号信息；主要卡片间距统一为 16px。
- 「我的收藏」复用「我的作品」的标题、说明和数量头部，并隐藏发布分类标签，保留卡片/画廊切换及收藏操作。
- 个性化设置改为 6 张独立卡片：字号、动效、作品列数、默认排序、公开主页隐私、导出默认值；每张卡片都有标题和说明。

### 个性化设置

- 字号支持小、标准、大。
- 动效支持完整、简洁、关闭；关闭后跳过编辑器开屏过渡，并减少社区卡片、画廊和顶部栏动画。
- 作品列数支持自适应、3 列、4 列、5 列，同时作用于卡片和画廊模式；900px 以下降为 3 列，620px 以下降为 2 列。
- 默认排序支持收藏最多、最新发布，进入社区时自动应用，顶部排序仍可手动切换。
- 公开主页隐私支持公开简介、公开所在地、公开统计；关闭后公开接口隐藏对应内容，统计显示「—」，本人账号管理仍可看到完整资料。
- 导出默认值支持 JPG/PNG、JPG 质量和输出尺寸；编辑器新建照片和导出弹窗沿用这些默认值。
- 所有偏好保存在 `landscape:prefs`，修改后立即生效；切换到其他页面时按当前页面重建对应控件状态。

### 搜索与筛选

- 浏览社区搜索保持原行为：搜索社区配方、标签和作者。
- 本人个人主页顶部搜索只搜索自己的已发布作品，支持搜索结果数量、空结果提示、分页和排序，搜索词写入 `author_search`。
- 「我的作品」增加紧凑搜索框和分类下拉，分类及数量只统计本人已发布作品。
- 「我的收藏」增加紧凑搜索框和分类下拉，分类及数量只统计本人收藏的作品。
- 搜索支持输入后自动筛选和回车立即查询，清空后恢复全部；搜索与分类可以组合使用。
- 发布记录、删除找回和社区页面不显示作品筛选栏；其他作者主页的搜索仍按社区范围处理。

### 后端与兼容

- `users` 幂等新增 `show_bio`、`show_location`、`show_stats`，默认公开，不迁移或覆盖已有作品、上传图和账号资料。
- `GET /api/me/categories?scope=mine|favorites` 返回当前范围的分类及数量。
- `GET /api/me/recipes`、`GET /api/me/favorites` 支持 `search` 和 `category` 参数。
- 作者作品集通过 `/api/recipes?author_id=...&search=...` 限定到当前作者。
- 作品、收藏和分类接口均校验登录身份；分类范围参数只允许 `mine` 或 `favorites`。
