# 编辑器功能与使用约定

## 工作区与历史

右侧为编辑、预设、AI 助手三个标签，共用当前照片和历史。编辑工具按基础调整、构图与相框、细节、精细调色、局部调整、暗角组织；直方图反映当前预览。参数支持滑块/数值、帮助和复位；组对比只暂时展示变化，不写入历史。

普通编辑在浏览器执行，不上传原图。最多 6 张照片、单张 20MiB/40MP、总文件 100MiB，容器尺寸在解码前检查。非活动照片保留文件和状态快照，不长期保留解码画布与 Worker。照片切换恢复各自参数、历史、AI 草稿及导出选项。

画布适配、缩放和显示对比不改变导出尺寸。拖动时降低工作栅格分辨率，松手恢复完整预览。Worker 不可用时使用兼容渲染路径。刷新/关闭页面不恢复工作区，请先导出照片并保存需要复用的常用配方。

## 工具语义

| 工具 | 行为 |
| --- | --- |
| 基础光线与颜色 | 曝光使用 EV；高光正值提亮、负值压暗；阴影、白色、黑色、对比度、色温、色调、饱和度、自然饱和度可继续手调 |
| 自动曝光与白平衡 | 采用受约束的统计估计；自动/取样白平衡同步可见色温/色调；取样应选择中性白/灰区域 |
| HSL 与曲线 | 红、橙、黄、绿、青、蓝、紫、洋红八色的色相/饱和度/亮度；整体/R/G/B 四通道曲线 |
| 细节 | 锐化、半径、边缘保护、明度/颜色降噪、清晰度、去朦胧；降噪在最终锐化之前执行 |
| 局部调整 | 画笔、线性、径向蒙版；擦除、羽化、反选、不透明度及局部参数；选区提示不写入导出 |
| 暗角与校准 | 明暗暗角及形状控制；RGB 原色各色相/饱和度校准 |
| 100% 查看 | 从原尺寸构图读取局部区域，可定位、切原图/编辑后；用于检查细节，不等同画布缩略预览 |

参数范围和步长由 `editor-core.js`、`editor-tools.js`、`editor-detail.js`、`editor-effects.js` 定义，蒙版容量与合法性由 `editor-masks.js` 定义，避免文档复制多份常量后失去同步。

## 预设与配方

六类 18 款预设支持分类、搜索、本机收藏、当前照片缩略图及 0–100% 强度。悬浮/聚焦预览，离开恢复，点击应用；已有编辑时提示确认。再次点击已选预设可移除，可撤销。经典五款滤镜保留。

切换预设替换它管理的整套风格字段，保留曝光、白平衡、亮度、构图、蒙版及暗角形状；用户手动修改的风格字段在继续调强度时受到保护。常用配方保存实际结果，不保存会话内的强度基线。

社区/常用配方默认只复用全局调色，保留本图构图与局部调整；用户可另外选择作者构图和局部选区。不同照片上的视觉结果不会必然相同。

## 构图与相框

裁剪支持边角拖动、移动、固定比例和源图像素输入。旋转支持翻转及自定义角度。拉直支持实时预览、自动裁去留白或保留空白。草稿应用一次写入历史，取消/Esc 保留原状态。

透视矫正支持自动分析和导引式操作。自动分析最长边 480px 的参考图中的直线结构；没有可靠结构时提示改用导引式。导引式每个方向最多两条参考线，共四条，端点可拖动/键盘微调。约束不足、重合或变换不稳定时禁止应用。可继续手动微调，默认保持宽高比自动裁边。迟到的分析结果不会越过取消操作生效。

相框是独立模拟预览，可调框形、卡纸留白与框宽，导出完整/50%/25% PNG。墙面和外部阴影仅用于网页展示；相框不修改普通照片导出、调色参数或配方。带框渲染受 64MP/单边 32767 像素限制，过大时需要降低尺寸。材质加载失败时禁用带框导出并允许重试。

## 配方版本与渲染契约

配方是 `{version, rendering, steps}` 的可执行 JSON，前后端均校验合法性；JSON 用于社区交接与私有快照，当前编辑器不提供文件下载/导入或粘贴配方入口。

| 版本 | 兼容含义 |
| --- | --- |
| v1–v5 | 保留旧曝光/高光、白平衡与细节响应，读取时迁移；`rendering.legacyTone` 保存必要的旧版明暗语义 |
| v6 | 普通工具、局部蒙版及实际参数输出 |
| v7 | 手动透视，或使用非零新暗角轮廓的配方 |
| v8 | 含 `upright` 步骤，保存归一化坐标上的 3×3 投影矩阵及 `autoCrop`，读取时不重新求解 |

导出根据实际内容选择 v6/v7/v8，并非所有照片都输出 v8。未知未来版本、不支持的操作和无效矩阵应报错。前端核心、Worker、原尺寸导出、同构图对比、细节区域及服务端 schema 必须保持相同语义；保留旧版本兼容与数据库迁移代码有实际数据用途。
