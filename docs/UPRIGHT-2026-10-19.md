# 构图工具与自动 / 导引式透视矫正（2026-10-19）

用户确认构图工具按“裁剪 → 旋转 → 拉直 → 透视矫正”从上向下排列，继续放在编辑标签下。“构图与相框”位于局部调整和暗角之间，首次打开仍折叠；相框预览保留在四项构图工具下方。

## 操作与边界

- **裁剪**调整比例和取景范围；**旋转**提供旋转、翻转和自定义角度；**拉直**调整倾斜角度，并选择是否裁去旋转后的留白。
- **透视矫正 / 自动矫正**在浏览器内分析最长边 480px 的当前构图参考图，寻找方向一致、具有连续边缘支持的直线对，计算投影变换。通过 Worker 执行；无 Worker 时保留本地兼容路径。没有可靠结构时提示改用导引式，保留已有预览，不新增历史；取消或离开后，迟到结果不会应用。
- **透视矫正 / 导引式**沿同一立面画两条竖直边或两条水平边，也可各画两条，同时约束两个方向。每个方向最多两条，总共四条。参考线随矫正后的照片移动，端点可拖动或用方向键微调（Shift 加大步长），支持删除重画。约束不足、参考线重合或变换不稳定时禁止应用。
- 自动 / 导引式完成后，可展开“手动微调”使用原有垂直 / 水平参数。默认按当前宽高比裁去空白，可关闭此选项查看完整变换；被裁边遮住的参考线端点，可先关闭自动裁边再调整。
- 所有矫正先预览，点击“应用校正”或 Enter 后一次写入历史，Esc / 取消保留原有状态。不会自动覆盖照片文件。

这是基于直线结构的几何分析，并非模型语义识别或 Lightroom Upright 的复刻。不处理镜头畸变，也不保证复杂多立面建筑、树枝或自然景物能自动校正；实际照片仍应由使用者判断预览。导引式应沿应当平行的边缘画线，不能将不同立面的任意边缘作为同一组约束。

## 渲染与配方约定

- 新步骤 `upright` 只允许配方 **v8**，参数严格为 `{matrix, autoCrop}`。`matrix` 是输入构图归一化坐标上的 3×3 行优先投影矩阵，最后一个元素为 1；`autoCrop` 是布尔值。保存求解后的矩阵，读取时不重新分析原照片。
- 矩阵须有限、可逆、保持画面方向及凸四边形，分母在图内不得跨零，拒绝过大或翻折变换；前端与共享后端 schema 同步校验。
- 含 upright 时导出 v8；只用原有手动透视 / 新暗角时仍为 v7，普通配方仍为 v6，继续读取 v1–v7。旧版本不得静默丢弃 upright 步骤。
- Worker 预览、兼容渲染、原尺寸导出、同构图前后对比、源图坐标蒙版和细节区域共用同一几何变换。
- 社区默认复用全局调色会排除 upright；只有勾选复用作者构图才带入。原生社区表单、编辑器适配和共享 schema 已同步接受 v8。另一成员尚未验收的图对 / 独立部署分支不混入本次改动，#4 继续保留；后续合入须保留 v8 兼容。
