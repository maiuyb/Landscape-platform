# 社区 #18 修复与图像资料入主线（2026-10-22）

本轮基于 `main/8836c38`，用户明确授权将成员分支图像 / 测试资料纳入主线，并完成 [#18](https://github.com/maiuyb/Landscape-platform/issues/18) 全部功能修复与边界验收。

## 修复

1. 后端图对解析接受根 `/uploads/` 和当前请求可信 `script_root` 下的上传路径，仅允许本地上传目录中的单个合法文件名；外部 URL、其他前缀、路径穿越和查询串不参与本地解析。HTTP 无 WebCrypto 时，两份同内容人工图片仍在后端规整为 single。
2. 前端根据真实社区地址计算应用前缀。历史根路径和当前带前缀图片都转到正确的缩略图路由，推荐 / 列表 / 我的上传 / 收藏 / 记录共用；详情原图同样兼容历史路径。缩略图失败只尝试一次原图，原图也失败则显示“图片暂不可用”，不循环重试。
3. 工具组恢复基础 → 精细 → 细节 → 局部调整 → 构图与相框 → 暗角。构图默认折叠，几何草稿仍在锁定其他工具时可操作；原构图专项不再需要跳过顺序断言。
4. 独立社区优先使用 Clipboard API，权限拒绝后尝试兼容复制，并检查结果；两条路径都失败时明确提示展开配方手动复制。配置了编辑器地址时只称“请求打开”，提醒弹窗受阻可手动访问；不声称自动传递照片 / 历史，不写跨源预览交接键。
5. 回归入口跟随 Gallery 欢迎页和主站登录 / 搜索，不削弱配方、历史或安全消息检查。另修复空编辑器入口重置已有照片条收起状态、关闭最后照片未返回欢迎页的状态衔接。

## 缩略图边界

独立模块 `backend/thumbnails.py` 不加载应用、配置或数据库，限制原图 40MP、单边 32767；在解码前检查尺寸。JPEG 使用缩小解码，EXIF 原位校正避免额外完整复制。

- 宽度归并到 200 / 400 / 800 / 1200 四档；同一文件版本不会因任意 w 参数产生无数缓存。
- 线程门与跨进程 OS 文件锁限制同时仅一份转码，等待总上限 5 秒；忙或缓存 I/O 不可用返回 503 / Retry-After。上传只保存和返回地址，取消同步预生成。
- 缓存总量限制为 256MiB / 1024 文件，生成后按访问时间淘汰旧缓存；清理超过十分钟的临时残留。原图不被缓存清理删除。
- 缓存键包含源文件 mtime_ns 与大小，原子写入，失败不留半成品。源文件在生成中变化则放弃结果。响应支持 ETag / 304，客户端缓存一小时，不再给可能重建的 URL 标记一年 immutable。
