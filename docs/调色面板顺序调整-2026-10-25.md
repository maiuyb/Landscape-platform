# 调色面板顺序与构图组操作补充

> **2026-10-25 更新：应要求已还原本次顺序、编号和构图组改动，当前代码恢复为修改前状态。** 以下内容保留为历史记录。

日期：2026-10-25

## 修改内容

1. 调整「调整照片」分组顺序：
   - 新顺序：基础调整 → 构图与相框 → 细节 → 精细调色 → 局部调整 → 暗角。
   - 「构图与相框」移动到第二位。
   - 「细节」与「精细调色」互换位置。
   - 其余分组的相对顺序保持不变。

2. 为「构图与相框」补充操作：
   - 新增「对比」按钮：按住时临时移除构图/裁剪/旋转/拉直/透视调整，松开恢复。
   - 新增「复位」按钮：清空已提交的构图操作，并关闭正在预览的裁剪、拉直或透视状态。
   - 对比可用性由 `groupAdjusted.composition` 判断，具体逻辑接入现有 `holdGroup()` / `resetToolGroup()` / `withoutGroup()`。

3. 按最终顺序重新分配罗马数字：
   - `I 基础调整` → `II 构图与相框` → `III 细节` → `IV 精细调色` → `V 局部调整` → `VI 暗角`。
   - 去掉罗马数字后的点号/逗号，保留数字和原有间距。
   - 未修改标题汉字和其他分组名称。

4. 修复构图组操作失效：
   - 原因：上一版把「构图与相框」放进了 `<fieldset :disabled="locked">`，裁剪/拉直/透视开始预览后 `locked` 会变为 `true`，导致整个构图组连同取消/应用按钮一起被禁用，看起来像前后端没有对应。
   - 修复：不再把构图组放进 `disabled` fieldset；「基础调整」和「细节 / 精细调色 / 局部调整」各自使用 fieldset。视觉顺序不变，预览期间取消/应用按钮不再被锁死。

5. 无照片时只改颜色，不禁用入口：
   - 构图组新增 `composition-inactive` 视觉态；没有照片/加载中/导出/分享/导入/相框导出/方案预览时只降低子工具颜色和透明度。
   - 不再使用 `fieldset :disabled`，所以「旋转」可以正常展开。
   - 无照片时点击「裁剪 / 拉直 / 透视矫正」会展开对应工具并显示“添加照片后可使用…预览”的提示，具体调整仍不会执行。
   - 「对比 / 复位」颜色与其它禁用分组一致，不再突出。
