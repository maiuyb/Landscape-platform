## 3. 已完成的功能与产品决定

- 编辑 / 预设 / AI 助手共用当前照片及历史；多图片工作区最多 **6 张**，点击切换，各自保留参数、构图、蒙版、历史、AI 草稿和相框设置。照片条只对齐左侧画布，可收起，底部书签箭头重新打开；右侧编辑栏延伸到页面底部。
- 编辑工具顺序：基础调整 → 精细调色 → 细节 → 局部调整 → **构图与相框** → 暗角。构图组默认折叠；内部按 **裁剪 → 旋转 → 拉直 → 透视矫正** 排列，相框位于其后。参数和按钮放在右侧编辑栏，与其他功能统一。
- 直方图位于编辑栏滚动区顶部，随栏内滚动离开，不是一个需要展开的小标签；2026-10-26 起不再固定常显。
- 裁剪与拉直分工明确；透视支持自动、导引式及手动微调。自动是直线结构分析，导引式最多两条水平和两条竖直参考线；不是语义识别或镜头畸变校正。
- 相框为白色木框 / 黑色木框 / 暖木纹框，使用实体框条和木纹材质；预览可调留白 / 框宽，并可独立导出带框图，普通照片与配方保持独立。
- 18 个预设与经典滤镜保留；已有编辑时，应用预设只询问是否按当前规则应用，不新增“重置调色”选项。一次滑条拖动只记一步撤销，不能恢复成按中间数值分段记历史。
- 社区配方默认只复用全局调色；**“同时复用作者构图”与“同时复用作者局部选区”分别可选**，不默认套用别人的裁剪或蒙版。
- 配方按实际步骤导出 v6 / v7 / v8，读取兼容旧版；`upright` 仅 v8。不要为了接社区而把新配方降成无版本 steps 或丢弃构图 / 局部调整。
