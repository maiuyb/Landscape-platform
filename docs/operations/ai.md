# AI 接入与运行

## 配置与模式

复制根 `.env.example` 为 `.env`，填写 `DASHSCOPE_API_KEY`，按所选兼容服务核对 `AI_BASE_URL` 与 `AI_MODEL`。当前仓库默认值为 `https://maas.qianwenaiapi.com/compatible-mode/v1` 和 `qwen3.8-flash`。这些是项目配置默认值，服务商可用性和计费以实际账号为准。

配置只从项目根 `.env` 加载，进程环境变量优先；更改后重启后端。密钥只在服务端使用。服务器由 systemd 加载 `/etc/landscape/landscape.env`。

| `AI_MODE` | 行为 |
| --- | --- |
| `auto` | 无密钥时明确返回固定演示，有密钥时请求云端 |
| `demo` | 始终固定演示 |
| `live` | 请求云端，缺配置时直接报错 |

`GET /api/ai/status` 只检查配置，不产生模型调用。“已配置”不等于实际请求成功。云端鉴权、网络、超时或解析失败会明确报错，不自动降级成演示或重试收费请求。

## 请求数据与执行

普通编辑、预览和导出在浏览器内完成。用户主动获取 AI 建议时发送最长边 512px 的当前编辑 JPEG、文字意图、主要参数、局部蒙版数量/构图操作数量，以及当前照片最近三轮成功交流。不会发送完整原图、蒙版笔迹或全部历史。后端不把参考图与交流正文落盘；上游服务的数据处理遵循该服务政策。

模型返回说明与 1–3 个方案，可包含一个已知预设、强度及受支持的绝对参数。浏览器与后端拒绝未知键、非数值、越界值和不支持操作。当前支持基础光线/颜色、HSL、细节、清晰度、去朦胧、暗角强度与原色校准；不能执行任意脚本、几何、蒙版或模型自创曲线。

方案先预览再应用，应用后可手调和撤销。请求期间继续编辑/换图时，返回结果需要核对照片及参数快照，过期方案被丢弃。失败与演示不进入云端成功交流上下文，切换照片隔离上下文。

## 资源与积分

默认最大输出 2200 tokens、每进程最多 2 个并发/每分钟 10 次请求；连接超时 5 秒、读取超时 45 秒，浏览器总等待上限 65 秒。请求正文最多 768KiB，JPEG 最多 384KiB，服务端拒绝超过 1024px 的参考图。一次用户请求至多一次上游调用。

真实云端 AI 要求登录并预留 1 积分。成功结算；失败或演示退款；异常中断预留超过五分钟后按规则回收。额度和错误处理见[账号与积分](accounts.md)。模型 token 统计不等于账单实收金额。

反向代理部署需设置不带路径的 `PUBLIC_ORIGIN=https://实际主机`，前缀由部署处理。进程级限流不跨多个进程共享；当前部署使用单 Gunicorn 进程、多线程。

## 验证

`npm run test:backend` 与浏览器 AI 专项使用模拟上游，验证契约、上下文、预览/应用/撤销、过期结果和错误处理，不调用真实付费模型。真实跨照片质量、连续交流、速度和费用应另行组织受控验收。
