# 账号、邮箱、积分与赞助

## 账号与公开资料

注册要求用户名、密码和有效邮箱验证码；提供密码登录、邮箱验证码登录、邮箱找回密码及已登录修改密码。密码使用带盐的密码派生哈希，兼容历史账号在登录时升级；密码重置/修改撤销旧会话。本人接口和公开作者接口分开，公开接口不返回邮箱、积分或密码字段。

用户中心包括个人主页、账号管理、我的作品、我的收藏、常用配方和个性化设置。作品/收藏搜索及分类只作用于本人对应范围，服务端从会话确定身份。作品软删除后七日内可找回，过期记录不能恢复。

字号、动效、列数、默认排序和新照片导出默认值保存在本机；公开主页简介/所在地/统计的可见性由账号服务端设置。更新偏好不会覆盖已有照片手动设定的导出值。私有配方保存参数快照和备注，不包含照片。

## 认证防护

认证计数、图片挑战及邮件验证码以 SQLite 事务维护。注册、发信、登录、校验、密码修改均有频率或正文大小限制；429 返回 `Retry-After`。登录失败达到阈值时增加图片挑战和短时冷却，不永久锁号。

图片挑战三分钟有效、一次使用并绑定来源/用途；邮件验证码十分钟有效、最多五次输错，区分注册/登录/绑定/重置用途。SMTP 未配置或投递失败时不返回可用于真实账号的演示验证码。已验证邮箱由数据库唯一索引约束。

生产代理需要覆盖转发头；只有显式启用 `LANDSCAPE_TRUST_PROXY=1` 时才信任受控回环代理。HTTPS 和 Nginx 认证入口限流由单独安装器配置，日常 main 更新不会替代基础设施安装。

## 邮箱配置

根 `.env.example` 包含 `SMTP_HOST`、`SMTP_PORT`、`SMTP_USER`、`SMTP_PASS`、`SPONSOR_ADMIN_EMAIL`。163 邮箱使用 SSL 465 及客户端授权码。服务器使用独立环境文件，修改后重启服务。

验证码和审批邮件由服务端生成，发送失败可恢复但不会发放无效证明。测试只使用 `@example.test` 和隔离服务的内存邮箱。真实收件箱投递需要上线后单独确认。

## 积分规则

- 新用户初始 10 积分，每日签到 +3，首次验证邮箱 +5；首次奖励不会重复发放。
- 真实 AI 请求先原子预留 1 积分，不在上游网络等待期间持有数据库锁；成功才结算，失败/演示退回。
- 签到、兑换、奖励在事务中增量修改，避免并发覆盖；兑换核销、到账及历史在同一事务完成。
- 体验口令保持每账号一次规则；管理员生成的兑换码默认二十四小时有效、单次核销。

## 赞助核验

系统没有接入支付宝支付回调。用户登记后向管理员发送确认页，管理员必须先自行核对实际收款。审批链接四十八小时有效，GET 只读，POST 带确认凭证才发码；一份申请只生成一枚码。投递失败复用原码重试，刷新页面不重复发码。

审批令牌只存摘要，审批页面转义用户内容并限制外部引用。配置公开 Origin 时不带 `/landscape` 路径；链接生成同时处理可信 Origin 和部署前缀。

管理员确需手动发码时使用 `scripts/generate_codes.py`，必须通过 `--database` 或 `LANDSCAPE_DB` 显式指定现有持久数据库。示例（会真实生成兑换码）：

```sh
sudo -u landscape /opt/landscape/current/.venv/bin/python /opt/landscape/current/scripts/generate_codes.py --database /var/lib/landscape/recipes.db --credits 50 --count 1
```
