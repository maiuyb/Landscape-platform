## 1. 参照依据与产品边界

- **Luminar Neo：**主要参照工具分组、参数语义、渐进展开和样板目录。界面依据用户提供的本机 1.22.1 四张截图；官方资料仅用于核对工具含义，可能涵盖更新版本，不自动纳入新增功能。
- **Fotor：**补充网页操作、展开后的参数控制、裁剪与应用/取消流程；后续重点观察 AI 入口和调用反馈。已观察基础编辑的 12 个展开面板，未完成全部 AI 功能、会员限制或效果质量验证。
- **Lightroom：**遇到效果实现问题时补充技术参考。**像素蛋糕：**仅作 AI 能力边界参考，不以其商业精修效果作为 Qwen 的验收标准。

目标仍是新手为主、摄影爱好者为辅的风景照片网页编辑器。支持 JPG、PNG、WebP 导入，单张最大 20MiB；PC 为主，手机核心路径可用。当前编辑状态只保留在页面内存中，刷新后不恢复。

采用 Luminar 的控制思路，自行实现浏览器图像处理。相同名称或数值不承诺相同画质；已截断为纯白/纯黑的像素不能通过滑块恢复真实细节。RAW、镜头数据库、专业色彩管理和 AI 生成效果不纳入这套基线。

## 3. 工作区与通用交互

用户 2026-10-15 在功能补全后确认直接修改原工作区，替代此前“前端暂缓”和参数/AI 并排的布局决定。PC 保留大画布及固定 344px 右侧工具面板（较窄桌面 320px），右侧顶部固定 **编辑 / 预设 / AI 助手** 三标签。默认编辑；标签只更换右侧内容，照片、缩放、构图、作品参数和历史共用。社区仍独立进入，无照片目录、评分、购买或会员入口。

编辑页一级为 **基础调整、精细调色、细节、暗角、局部调整**。基础调整默认展开，先展示曝光/对比/高光/阴影，更多光线收白色/黑色/亮度，基础颜色与白平衡另作二级；精细调色收 HSL、曲线、原色校准；细节收清晰度/去朦胧及二级锐化/降噪；暗角先强度，再展开形状与位置。最多两层工具展开，直方图可展开，关闭组以“已调整”提示效果存在。各组保留展开状态，不强制互斥。

1. 参数行紧凑呈现名称、可编辑数值、滑条和可见复位；双击名称可复位。说明用问号帮助，鼠标悬浮/键盘聚焦/触摸点击可读，Esc 退出；必要的绘制/裁剪操作说明仍直接显示。
2. 所有效果默认中性。单项、组和整图复位均可撤销。基础组复位覆盖光线/基础颜色/白平衡，基础颜色复位不影响精细调色；精细组复位 HSL/曲线/校准，局部组复位清除蒙版并可撤销。
3. 连续拖动或一次数值输入一条历史；标签、分组、HSL/曲线选择、缩放与对比属于查看状态。组标题“对比”按住鼠标或空格临时关闭这组预览，松开恢复，不改变参数、历史或输出。
4. 裁剪、拉直、局部调整入口靠近画布；附加旋转/翻转在构图菜单，操作后/外部点击/Esc 关闭。全局撤销/重做在画布下方，导出在顶部，配方导入/导出/复制放在右侧固定底部展开项。
5. 预设独立标签，现有自然/山林/日落/夜景/胶片/黑白六类各三款，支持分类、搜索、收藏、当前照片缩略图、悬浮/聚焦预览、离开恢复、点击应用、立即切换、强度与撤销；触摸点击直接应用。原五款收进经典滤镜，保留旧文件行为。完整配方与 AI 继续显式预览/应用/取消。
6. 切标签结束悬浮/方案临时预览和蒙版绘制，保留已完成笔画及所有已应用修改；保留每个标签的滚动、分类和 AI 描述草稿。裁剪/拉直草稿仍保留并明确显示操作栏，需显式应用/取消。
7. AI 快捷入口定位同一个 AI 标签输入框。描述和快捷意图进入既有推荐接口，建议显示变化摘要、可查看相关工具；后台完成不跳转，以标签提示。编辑期间改变照片会使旧建议失效。未连接模型的固定配方明确标为演示，不伪称理解用户描述；当前保存会话展示，但不宣称已有云端多轮记忆。
8. 对比沿用“原图 · 同构图”。主工作预览允许缩小，原图像素查看和完整输出共用原效果定义；标签不改变照片尺寸。
9. 工作预览优先于缩略图；缩略图在 Worker 按需生成、过期结果丢弃并释放位图。兼容路径分帧生成，缩略图完成前有更新提示。
10. 手机保留上方照片和下方三标签面板，面板内独立滚动，避免展开工具产生数千像素页面；键盘标签支持方向/Home/End，保留选中与控制区域语义。

用户已同意 Gemini/Argon 检索复核后的接入方向，并要求完善预设、尝试轻松明快的米色。18 款使用原生参数重新调校，来源固定到上游版本并保留 MIT 声明；不把 Luminar 的专有文件或图片直接打包。界面采用奶油色面板、米色背景和鼠尾草绿强调，照片四周用较中性的灰米色。检查与边界见 DEVELOPMENT-STATUS.md 第 21 节。

### 3.1 预设切换、强度与手动调整

- 一套风格控制对比度/高光/阴影/白黑场/饱和度/自然饱和度、八色 HSL、曲线、原色校准、细节、清晰度/去朦胧与暗角强度。曝光、亮度、白平衡、构图、蒙版及暗角形状保持用户设置；新套装替换先前风格，不叠加上套参数，旧经典滤镜也由新选择替换。
- 第一次应用保存风格参数的基础状态；切换复用同一基础，强度 0–100 在基础与目标参数间插值。0 为基础，100 为目标；曲线按共同横坐标采样并保持有效控制点，单次拖动形成一条历史。移除预设返回基础状态。
- 手动改过的字段在基础与目标两端同时固定；曲线按整个通道固定。之后调强度/移除不覆盖这些手动结果。换另一套则重新替换风格控制字段，原手动结果可通过撤销恢复；曝光、白平衡、构图和蒙版始终不由预设接管。
- 预设会话随撤销/重做恢复，导出仅存实际参数，版本仍为 6；在新照片上导入可复现效果，但不会恢复会话强度与选择名称。完整配方/AI 应用结束旧预设会话，避免关联到错误基线。收藏只记预设编号于当前浏览器，不保存照片，不等于作品跨会话保存。
- 黑白新预设在八色 HSL 内同时去色与调明度，再经过曲线，避免整体饱和度先降至 −100 导致原颜色信息丢失。保留原内置黑白滤镜和旧配方像素语义。

## 4. 第一批 E1：光线、基础颜色与参数一致性

### 4.1 光线

| 控制 | 建议范围 / 步长 / 默认 | 产品语义 |
|---|---|---|
| 曝光 | −3～+3 EV / 0.05 / 0 | 整体曝光；正值更亮，负值更暗。显示两位小数和 EV |
| 对比度 | −100～100 / 1 / 0 | 增强或减弱明暗差异；先提供可靠的普通对比度 |
| 高光 | −100～100 / 1 / 0 | 调整亮部；正值提亮，负值压暗 |
| 阴影 | −100～100 / 1 / 0 | 调整暗部；正值提亮，负值压暗 |
| 白色 | −100～100 / 1 / 0 | 调整白点和最亮端，与覆盖较宽亮部的高光控制有所区别 |
| 黑色 | −100～100 / 1 / 0 | 调整黑点和最暗端；正值抬黑，负值加深 |
| 亮度（更多控制） | −100～100 / 1 / 0 | 保留现有整体亮度调整与旧配方兼容，避免默认与曝光并列争夺主要入口 |

光线组内先列曝光、对比度、高光、阴影，白色/黑色作为相邻子组。Luminar 截图称“智能对比”，本项目先标为“对比度”；自适应算法通过照片评估后再决定是否升级名称。

上述明暗控制方向依据 [Skylum Develop 工具说明](https://support.skylum.com/editing-tools/essential-tools/develop-raw-develop)；范围和步长为本项目建议值，不照搬 Luminar 内部参数。

### 4.2 基础颜色

| 控制 | 建议范围 / 步长 / 默认 | 产品语义 |
|---|---|---|
| 色温 | −100～100 / 1 / 0 | 负值偏冷，正值偏暖；当前普通图片采用相对调整，不显示虚假的开尔文温度 |
| 色调 | −100～100 / 1 / 0 | 负值偏绿，正值偏洋红 |
| 饱和度 | −100～100 / 1 / 0 | 调整整体色彩强度 |
| 自然饱和度（鲜艳度） | −100～100 / 1 / 0 | 优先影响较淡颜色，对已经鲜艳的颜色减少增强；不能仅复制饱和度算法 |

界面主标签统一为“自然饱和度”，说明中保留“鲜艳度 / Vibrance”，便于用户对应截图和常见术语。其与饱和度的区别参考 [Skylum Color 工具说明](https://support.skylum.com/editing-tools/essential-tools/color)。

### 4.3 E1 完成条件

- 新增白色、黑色、自然饱和度在中性设置下不改变图像，在渐变和真实照片上表现出各自作用范围；不出现明显色带、断层或普遍色偏。
- 曝光具有明确 EV 语义；高光与阴影、白色、黑色的正负方向一致。实际效果应可区分曝光、亮度、端点与分区明暗调整。
- 右侧分组和数值输入可用；新增状态可撤销、复位、预览、导出和重新读取配方。
- 旧配方兼容按第 8 节验证，不能直接改符号或单位而改变历史配方含义。

### 4.4 后续反馈新增：自动调整与取样

自动曝光采用亮度直方图中位数估计，并用高亮分位数限制增益，结果限制在 ±1.5 EV；写入曝光参数，支持撤销。自动白平衡采用低饱和像素的灰世界估计，优先近中性区域，排除过暗/截断区域并约束通道增益；候选不足时提示用户取样或手调，不改变原设置。这是普通图片上的保守实现，不能恢复截断细节，也不能判断日落等暖色是否有意保留。[OpenCV GrayworldWB](https://docs.opencv.org/4.x/d7/d71/classcv_1_1xphoto_1_1GrayworldWB.html) 提供灰世界及按饱和度选像素的技术参考。

白平衡取样笔让用户选择应呈中性白/灰的区域，平均局部像素后求校正；过暗、透明或不可靠的截断区域拒绝取样。自动/取样结果直接写入色温与色调，两轴显示两位小数、滑条步长 0.1，之后从当前值微调；单项复位只恢复该轴，两轴复位为中性。模式和数值可撤销/重做并保存。相对数值不是开尔文；彩色物体不能作为可靠白点。

2026-10-15 根据用户反馈，将新自动/取样结果统一到这两根滑条，避免图像改变但数值仍为 0。新模型用通道比例的对数坐标及按中性样本亮度归一化的增益，该修正使用版本 5。旧纯增益配方可派生显示坐标，首次手调转换；旧增益与附加温调同时存在的复合配方保持旧语义和原效果，重新自动/取样进入统一控制。细节与验证见开发状态第 14 节。

## 5. 第二批 E2：HSL、曲线与直方图

### 5.1 八色 HSL

采用用户第二张截图的结构：下拉选择 **色相 / 饱和度 / 亮度**，下方固定显示 **红、橙、黄、绿、青、蓝、紫、洋红** 八个色段。每段保存三个独立值，总计 24 项，建议均为 −100～100，步长 1，默认 0。

- 切换下拉项只改变显示，保留其他模式的设置；提供当前色段复位和整个 HSL 复位。
- 色相改变所选颜色的偏向，饱和度改变其强度，亮度改变其明暗。轨道展示相应方向；色相滑块的实际角度映射由照片效果评估确定。
- 色段间平滑过渡，红色在色环首尾连续；低饱和区域降低色相调整影响，避免灰色被无意染色。色段范围以原始色相判定，避免一次处理把像素反复归入下一色段。
- HSL 是按颜色选择，不是空间蒙版。例如修改蓝色会同时影响蓝天、蓝水和其他蓝色物体；AI 不得将其描述为“只改天空”。

HSL 模式含义依据 [Skylum Color 工具说明](https://support.skylum.com/editing-tools/essential-tools/color)，八色布局依据用户截图。本项目不在此批加入全局色相轮转或自动去色偏滑块。

### 5.2 曲线

提供整体、红、绿、蓝四个通道，选择器带文字标识。横轴输入暗→亮，纵轴输出暗→亮；上移控制点使相应色阶更亮，下移更暗。默认对角直线为中性。

支持添加、拖动、选中和删除中间控制点，端点可移动并单独复位；控制点按横坐标排序，防止重合导致非法插值。建议每通道最多 10 个点（含端点），并提供选中点的数值输入与键盘调整。保留当前通道和全部曲线复位。

曲线之间采用固定、可复现的处理顺序；预览、输出和配方恢复一致。非线性插值需约束过冲，输出保持合法范围。底部额外的黑/中/白场手柄不列入 E2 必做，避免与光线组重复控制。

E2 实现采用形状保持的 PCHIP 插值，每通道最多 10 点；端点横坐标固定在输入两端、纵坐标可调。选中点支持 0–255 输入、方向键（Shift 加大步长）和中间点删除。处理顺序为白平衡增益 → 光线/基础颜色 → HSL → 整体/R/G/B 曲线 → 基础滤镜，预览和原尺寸输出共用。插值方法参考 [SciPy PchipInterpolator](https://docs.scipy.org/doc/scipy/reference/generated/scipy.interpolate.PchipInterpolator.html)，自行用 JavaScript 实现。

### 5.3 直方图与 E2 完成条件

提供亮度及 RGB 分布，随当前编辑预览更新，可使用降采样数据并合并更新。直方图说明反映预览的分布，不冒充 RAW 传感器数据；图表本身不产生编辑历史。

E2 验收包括：24 项 HSL 切换后不丢失、色段边界连续、灰阶保持中性；四通道曲线独立保存、对角线无效果、复位与撤销正确；拖动曲线及滑块时直方图与画布最终一致；配方往返和原尺寸输出覆盖新工具。

## 6. 第三批 E3：细节与构图

### 6.1 锐化与降噪

| 控制 | 建议范围 / 默认 | 要求 |
|---|---|---|
| 锐化 | 0～100 / 0 | 增强边缘细节；强度为 0 时完全中性 |
| 锐化半径 | 0.5～3.0 源图像素 / 1.0 | 控制边缘影响宽度；预览需考虑源图与预览缩放差异 |
| 锐化边缘保护 | 0～100 / 0 | 数值越高越偏向明显边缘，减少天空等平坦区域被过度锐化；提示对应 Luminar 的“锐化蒙版” |
| 明度降噪 | 0～100 / 0 | 降低亮度噪点，同时保护边缘和纹理 |
| 颜色降噪 | 0～100 / 0 | 降低杂色噪点，避免整体去饱和或颜色渗漏 |

先实现这五项。截图中的细节保护、细节遮罩和额外降噪强度作为后续候选，不先堆出无可靠作用的滑块。边缘保护由算法计算，和用户绘制的局部蒙版区分；E3 当时不要求笔刷/区域选择；后续用户确认的手绘蒙版范围见 6.4。

提供 100% 查看提示和入口，评估细节需覆盖真实照片局部，不能只靠适配画布的缩略图。处理顺序明确并保存版本，原则上降噪先于最终锐化；工作预览与输出按同一效果定义处理，性能优化不能偷偷取消输出效果。

E3 实现：细节在现有颜色/曲线/滤镜后处理，先明度/颜色降噪，再最终亮度锐化。降噪为按原始亮度及色差引导的双向分离双边近似，分别平滑亮度和色差，保留明显边界；锐化为高斯模糊差值的亮度 USM，边缘保护按局部梯度抑制低对比变化，增量约束以减少光晕。算法自行实现，不能将普通平滑宣传为 AI 纹理恢复。技术参考见 [SOURCES.md](SOURCES.md)。

半径以源图像素计，工作预览按源图与预览比例缩放；低分辨率近似保留最小滤波宽度，缩略预览不能代替 100% 判断。100% 窗口读取当前构图的全尺寸局部，带完整邻域再裁回显示块，确保局部与同参数完整尺寸 PNG 区域一致；点击照片选位置，原图/编辑后切换不改变历史。窗口原图指同构图未调色/未做细节处理的原图。

预览沿用 Worker，空间处理分块携带邻域，避免为大图的每个通道同时分配全尺寸工作数组。原图像素窗口的几何底图按构图缓存；关闭或更换照片后释放。12MP 源图已验证，但超大图和兼容降级路径仍可能更慢；完整输出当前在主线程重建。

### 6.2 构图

- 裁剪框支持角点/边缘手柄和框内移动，边界不能越出可裁剪区域；显示外部遮罩、保留尺寸与可开关的三分线。
- 提供自由、原图比例、1:1、3:2、4:3、16:9 及竖向对应比例，支持比例锁定和宽高输入；尺寸以源图像素解释，不把屏幕显示像素当作输出尺寸。
- 拉直滑块建议 −45°～45°，带数值输入；保留现有 90° 旋转、自由角度旋转及水平/垂直翻转。连续旋转不得反复重采样源图。
- 构图采用“应用 / 取消”，提交一次历史。拉直可选择自动裁去空白或保留空白，并在提交前预览输出范围；保留空白时 PNG 透明、JPG 白色填充，延续现有说明。

拉直已实现：±45°、0.1° 步长和数值输入，拖动暂存预览，应用一次历史，取消/Esc 恢复。自动裁边取旋转后位于原图范围内的居中矩形并保持进入拉直时的宽高比，不宣称是任意比例的最大面积裁剪；留白采用完整旋转外框。裁边依据当前构图的矩形边界，只消除本次旋转产生的空白，不识别源图已有的透明区域。每次预览/输出从源图按几何操作重建，不从上一次显示图反复旋转。裁剪三分线和拉直辅助线共用可见开关偏好，不属于配方效果。

### 6.3 E3 完成条件

对高 ISO、树叶/草地、建筑边缘和天空区域检查锐化光晕、噪点放大、涂抹和杂色处理。裁剪尺寸、锁定比例、拉直后的边界、取消/撤销以及输出像素一致；PC 可直接操作，手机也能完成裁剪与应用。

### 6.4 E4：清晰度、去朦胧、原色校准、暗角与手绘蒙版

用户 2026-10-15 在 E3 后补充此范围，并澄清“调三原色”指 Lightroom 校准中的红/绿/蓝原色色相与饱和度；第一版蒙版选择画笔、线性渐变、径向渐变。以下替代此前对这些功能的暂缓决定。**此批只增加功能及必要控件；菜单重组、收紧二级层级与整体前端调整留待用户共同讨论。**

| 功能 | 当前控制及默认 | 语义与实现边界 |
|---|---|---|
| 清晰度 | −100～100，默认 0 | 中尺度亮度局部对比，负值柔化；多次盒式低通，限制增量并降低两端影响，与锐化分开 |
| 去朦胧 | −100～100，默认 0 | 正值减雾、负值加雾；借鉴暗通道先验的大气散射近似，限制透射率并减弱高亮近中性区域的校正；非 AI/深度估计 |
| RGB 原色校准 | 红/绿/蓝各色相、饱和度，均 −100～100，默认 0 | 参考 Adobe Calibration 控制含义，自行实现普通解码 RGB 的原色基底变换，保持中性灰及未截断亮度；不同于八色 HSL。不是 RAW/DCP 配置文件，也不宣称数值与 Lightroom 等效 |
| 暗角 | 默认选择“暗角 · 压暗边缘”，强度 0～100 默认 0；范围 50、羽化 70、圆度 0、中心水平/垂直各 50，其余范围 0～100 | 向右增强黑色暗角；要提亮须明确选择“亮角 · 提亮边缘”。中心按最终构图定位，羽化连续；不改变透明度 |
| 蒙版 | 画笔、线性渐变、径向渐变；最多 6 层，默认中性局部调整 | 每层独立命名、启用/停用、反选、不透明度；画笔可擦除，直径按原图短边百分比、羽化影响之后笔画；线性起点 0、终点 1，两端间距决定过渡；径向中心为内区、支持羽化及反选 |

局部参数为曝光、对比度、高光、阴影、色温、色调、饱和度、清晰度、去朦胧；范围沿用相应全局控制。全局面板始终修改全局，只有明确标注“局部”的控制修改当前层。蒙版选择、红色覆盖、绘制/擦除偏好属于工具/查看状态，不进入照片输出；层形状、参数、启用、反选、不透明度进入历史和配方。

蒙版矢量坐标固定在原图归一化空间，通过同一几何变换跟随裁剪、旋转、翻转及拉直。每笔/一次形状拖动提交一条历史；渐变端点、径向中心/范围可拖动，也支持方向键 1 源图像素、Shift 10 像素。画笔每层最多 64 笔、4096 点、每笔 512 点；达限明确提示保留已完成内容，可分笔、新建层或清空笔画。不是按住越久越浓的喷枪。

处理顺序：几何 → 白平衡 → RGB 原色校准 → 原有光线/基础颜色/HSL/曲线/滤镜 → 全局去朦胧/清晰度/暗角 → 降噪/锐化 → 按列表顺序局部蒙版混合。空间处理使用完整邻域的分块与全画面大气光估计，100% 局部沿用全画面统计及坐标，避免暗角重新居中或去朦胧局部重新估计。适配预览仍为近似；原图像素窗口和输出用于检查细节。高强度局部对比/去朦胧会放大噪点、截断或产生光晕，默认不增加效果。

2026-10-15 根据用户反馈修正暗角交互：不再让同一根正负滑条向右直接变白。界面强度统一为 0～100，暗角为默认方向，亮角需明确选择。版本 6 内部仍保存带符号的 amount（负暗、正亮），因此旧配方无需改变，导入会显示正确方向与绝对强度。强度复位保留所选方向，整组/整图复位及更换照片恢复默认暗角；切换非零效果方向可撤销。

当前配方 **版本 6**，新增 `effects`（含清晰度、去朦胧、原色校准、暗角）与 `masks.params.layers`；继续读 1–5，旧文件新增项缺省中性；版本 5 白平衡模型继续保留。保存的是参数与归一化选区，复用到其他照片须自行判断适配。蒙版关闭查看、画笔大小偏好等不写入配方；详细证据及限制见开发状态第 15 节。

参照：[Adobe 图像色调与颜色 / Calibration](https://helpx.adobe.com/lightroom-classic/desktop/process-and-develop-photos/image-tone-color.html)、[He / Sun / Tang：Single Image Haze Removal Using Dark Channel Prior](https://people.csail.mit.edu/kaiming/publications/pami10dehaze.pdf)。控制含义和算法思路分别参考；实现为本项目自有近似。

## 8. 状态、配方与兼容要求

新工具须接入统一参数状态、历史、分组复位、样板强度、AI 校验、配方和输出，不能只增加界面控件。曲线点、HSL 24 项和细节参数都应可序列化；未知操作明确提示，合法的已知部分仍可预览。

E1 前的本地配方为版本 1，曝光保存 −100～100，处理倍率是 `2^(value/50)`；高光正值压暗。E1 新导出采用版本 2，改曝光单位和高光符号，并实施显式迁移：

- 旧曝光按 `value / 50` 转为 EV；旧高光需转换符号。
- 转换单位/符号只保证语义对应；若同时升级算法，必须用旧版渲染或迁移效果验证处理视觉差异，不能宣称数值转换自然保证逐像素相同。
- 不修改版本 1 的既有含义；导入老配方时说明兼容处理，保留旧文件。新功能缺省为中性，不能凭空新增效果。
- 参数有限值、范围、曲线点和几何边界在导入/AI 入口统一校验。拒绝不支持的新版本时给出清楚提示。
- 社区分支的配方协议在后续接入时单独核对，不假设现有社区 API 已支持这些新字段。

E1 实现使用 `rendering.legacyTone` 保留旧版高光/阴影响应，手动改变旧版高光或阴影时，仅该项切换新版平滑响应，界面提示且可撤销。E2 阶段导出升级到版本 3：增加 `white-balance`（通道增益和模式）、八个 `hsl` 操作（三项值）及四个 `curve` 操作（控制点）；继续导入版本 1/2，新字段缺省中性，保留 `rendering.legacyTone`。旧后端/AI 无版本列表仍按版本 1 读取；新版方案须保留完整版本封装。无效新操作提示并忽略，合法已知部分仍可预览。

E3 初次导出为版本 4：增加 `detail`（五项控制）和顺序几何操作 `straighten`（角度/是否自动裁边）。继续读取版本 1/2/3，新增细节缺省中性（半径 1，其他 0），不改变旧文件效果；版本 4 的同类操作采用本节处理顺序和源图像素半径定义。界面的 100% 查看位置、开关及辅助线属于查看状态，不写入配方。

白平衡反馈修正时升级到版本 5，使用 `white-balance.params.model='relative'` 区分统一色温/色调控制，旧 1–4 及没有此标记的增益加偏移方案维持原渲染；重新保存时保留旧含义。统一模型由色温/色调推导增益，导入不允许用另一个隐藏增益覆盖可见坐标，避免面板和输出再次分离。

共同验收要求：

1. 中性参数不改变解码后的像素（除明确的几何/输出尺寸变化）；PNG 用像素对比，JPG 考虑有损压缩，不能要求文件字节相同。
2. 代表照片无明显色阶断层、异常色偏、透明边缘污染；极值的截断或过强效果应可理解、可复位。
3. 所有新操作可撤销/重做、分组复位、同构图对比、样板/AI 预览取消；刷新生命周期与现有说明一致。
4. 原尺寸输出、不同输出比例和配方重新导入保持预期效果；测试包含旧版配方和不合法参数。
5. 静止时最长边 1200 像素预览，拖动时可用 640 像素后台预览并在松手恢复，显示尺寸不随分辨率跳动。暂以常见滑块 200ms 内反馈为目标，另需检查持续拖动的输入响应、主线程阻塞和最后状态一致性；单次渲染器计时不代表交互验收。曲线、直方图和细节分别测量，记录浏览器、设备、图像尺寸和数据，不能沿用旧测试宣称已达标。
6. 工程检查与照片效果检查由开发者完成，不要求用户每批手动测试。审美或操作取舍通过少量代表性结果征求反馈；正式无指导任务测试另行组织，验证查找、理解、复位和导出。发现严重理解问题时先调整交互，再扩展工具。
