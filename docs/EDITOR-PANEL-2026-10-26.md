# 编辑栏与粘贴配方 · 2026-10-26

按用户反馈调整编辑器，保留现有 Gallery 美术、配方版本和预览语义。

- 基础调整默认收起，用户仍可自行展开。
- 直方图放在编辑栏滚动区顶部，随栏内内容滚动离开；不再固定常显，不改成折叠标签。
- 删除“调整照片”上方的烫金英文及对应占位。
- “配方与作品”默认展开，主标题采用与“调整照片”相同的 Gallery 衬线字体、20px 字号和字重。
- 新增“粘贴配方”：浏览器允许时读取剪贴板；无法读取、拒绝读取或未读到内容时提供手动粘贴框。无效内容在框内提示，可取消或按 Esc 退出。
- 读取后复用现有配方详情、范围选择和预览流程，默认仅复用全局调色；作者构图、局部选区分别可选。用户确认应用前不修改当前编辑。手动框关闭会清空粘贴内容，剪贴板文本不上传或持久保存。
- 剪贴板读取期间若照片切换、关闭或进入锁定操作，迟到结果不会针对另一张照片打开配方。
