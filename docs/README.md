# 文档导航

本目录是项目组两位成员共同确认的开发初期产品基线。产品方向和初期范围可直接用于开发；用户假设、界面细节和实现约束仍应通过测试与迭代完善。

2026-10-14 用户确认以 Luminar 为依据的图片编辑基线，并在性能修正后反馈交互。新增范围以 EDITOR-BASELINE.md 1.2 及 PRD 0.4 为准；E1/E2 和新裁剪/滤镜交互已本地实现，E3 接续。不将新增规格表述为两位成员已共同复核，验证证据见开发状态第 11 节。

## 建议阅读顺序

1. [PRD：开发初期产品需求基线](PRD.md) — 当前产品方向、用户、功能范围、体验要求和开发路线；实施时以此为主。
2. [Luminar 编辑功能基线](EDITOR-BASELINE.md) — 当前编辑工具、参数语义、E1–E3 顺序、暂缓范围和验收；编辑细节以此为准，功能目标不代表已实现。
3. [开发初期产品决策记录](DECISION-INPUT.md) — 初期共同方向与后续用户决定。
4. [组员建议整理与开发决策记录](FEEDBACK-SYNTHESIS.md) — GitHub Issue #1 建议如何整理进当前产品基线，以及实现和研究时仍需具体化的事项。
5. [用户体验调研与竞品评估计划](UX-RESEARCH.md) — 竞品观察、访谈、可用性任务和研究记录方法。
6. [产品与开源项目参考资料](SOURCES.md) — 公开产品说明、开源项目与来源链接。
7. [开发状态](DEVELOPMENT-STATUS.md) 与 [交接包](DEVELOPMENT-HANDOFF.md) — 区分历史记录、当前本地实现及下一步工作。

## 使用约定

- PRD 是开发时的主需求基线；已确认方向可执行，观察到用户问题后记录证据、调整设计并更新版本。
- 编辑细节遵循 EDITOR-BASELINE.md；原始需求规格说明书中的八参数限制已经被替代。已实现能力以开发状态为准。
- 本目录中的竞品功能仅供参考，不代表本项目必须实现对应功能。
- 暂挂问题和公网展示前的安全事项见 PRD 第 11–12 节；不应将课程展示环境描述为商业生产服务。
