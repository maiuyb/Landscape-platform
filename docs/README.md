# 文档导航

文档按用途组织，描述当前仓库。阶段交接、旧分支状态、一次性修复日志及已撤回的界面方案已合并或删除；历史过程可通过 Git 查询。研究计划与待验证假设单独标明，不将工程测试当作用户研究结论。

| 分类 | 文档 | 用途 |
| --- | --- | --- |
| 产品 | [产品需求](product/requirements.md) | 定位、目标用户、当前范围、验收原则与评审问题 |
| 产品 | [编辑器说明](product/editor.md) | 工具、预览与历史、会话工作区、配方兼容 |
| 研究 | [用户研究计划](research/plan.md) | 参与者、访谈、竞品观察与任务脚本 |
| 研究 | [参考资料](research/references.md) | 产品、交互及图像处理参考入口 |
| 开发 | [技术架构](development/architecture.md) | 源码模块、数据流和修改入口 |
| 开发 | [测试说明](development/testing.md) | 自动化、专项回归、人工效果评审 |
| 开发 | [素材与许可](development/assets.md) | 产品素材、预设、成员摄影资料及声明 |
| 开发 | [维护约定](development/maintenance.md) | 清理边界、目录和后续维护原则 |
| 运维 | [AI 接入](operations/ai.md) | 模式、配置、请求数据、执行限制 |
