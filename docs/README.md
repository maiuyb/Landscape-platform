# 文档导航

本目录整理产品需求、体验研究计划、参考资料和意见来源。个人意见、组员建议及研究假设不自动构成项目组决定。

## 建议阅读顺序

1. [PRD：产品需求基线](PRD.md) — 当前产品方向、用户假设、需求范围、体验要求和已知限制。
2. [用户体验调研与竞品评估计划](UX-RESEARCH.md) — 竞品观察、访谈、可用性任务和研究记录方法。
3. [项目意见综合整理](FEEDBACK-SYNTHESIS.md) — 将成员建议与后续个人答复整理为待评审方案；不是已批准需求。
4. [项目成员个人意见与待议项](DECISION-INPUT.md) — 一位成员对产品决策问题的个人回答及仍需验证的内容。
5. [产品与开源项目参考资料](SOURCES.md) — 公开产品说明、开源项目与来源链接。

## 决策与版本边界

- PRD 是当前需求讨论基线；含有待验证假设和个人意见，不应视为最终团队批准的范围。
- 综合稿记录了 GitHub Issue #1 的建议和个人补充意见。正式采纳前，需由项目组讨论，并根据用户研究与实现可行性更新 PRD。
- 参考产品的功能仅用于分析，不等于本项目承诺实现对应功能。
